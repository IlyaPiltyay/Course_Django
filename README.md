# Сервис рассылок

Этот сервис предназначен для управления и отправки электронных рассылок с возможностями создания, редактирования и удаления рассылок. Он позволяет пользователям управлять своими рассылками и отслеживать статистику.

## Функции

- **Создание рассылки**: Пользователи могут создавать новую рассылку, указывая тему, содержание и список получателей.
- **Редактирование рассылки**: Пользователи могут изменять информацию о существующих рассылках.
- **Удаление рассылки**: Удаление рассылок
- **Статистика**: Возможность просмотра статистики о рассылках, включая общее количество рассылок, активных рассылок и уникальных подписчиков.
- **Кэширование**: Использование кэширования для повышения производительности и снижения нагрузки на базу данных.

## Технологии

- **Django**: Фреймворк для разработки веб-приложений.
- **PostgreSQL**: Реляционная база данных (или другая ваша база данных).
- **HTML/CSS**: Для представления интерфейса пользователя.
- **Bootstrap**: Фреймворк для разработки адаптивных веб-интерфейсов (если используете).
